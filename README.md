# Data Black Box

## Project Overview
Data Black Box is a Data Incident Detection, Investigation, and Root Cause Analysis Platform.

The platform detects data quality issues, tracks incidents, and helps investigate their possible root causes.

## Dataset
Solar Power Generation Data

Source: https://www.kaggle.com/datasets/anikannal/solar-power-generation-data

## Technology Stack
- Python
- SQL
- PostgreSQL
- Apache Spark
- Apache Kafka
- Apache Airflow
- Docker
- Grafana

## Main Components
- Data Ingestion
- Data Processing
- Data Quality Checks
- Fault Injection
- Root Cause Analysis
- Incident Tracking and Visualization
